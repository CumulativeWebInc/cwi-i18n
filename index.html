cwi-i18n

One translation system for every CWI app — humans and agents. Zero dependencies, $0, served from GitHub Pages.

Integrate in 3 steps

  1. Tag your UI strings: <p data-i18n="hero.tagline">English fallback</p>
  2. Add the loader before </body>: 
    <script src="https://cumulativewebinc.github.io/cwi-i18n/i18n.js" data-app="<your-app-id>"></script>
  3. Publish your tables at /tables/<app-id>/<lang>.json in this repo and register the app in i18n-manifest.json.

You get: a floating globe language switcher (auto-injected, mobile-friendly), ?lang= URL override, localStorage persistence, and first-visit auto-detect from navigator.language.

Key conventions

AttributeEffect
data-i18n="key"replaces element text
data-i18n-ph="key"replaces placeholder
data-i18n-title="key"replaces title
data-i18n-aria="key"replaces aria-label

Key style: section.name — lowercase, dots for hierarchy (e.g. clearance.line, share.button). For JS-rendered content use CWI18n.t("key") and call CWI18n.apply() after rendering (a MutationObserver also picks up new nodes automatically).

// programmatic use
CWI18n.init({ app: "sync-audition", defaultLang: "en" }).then(function (lang) {
  document.title = CWI18n.t("meta.title") || document.title;
});
CWI18n.setLang("es");          // switch at runtime
CWI18n.getLang();              // "es"
CWI18n.supported;              // ["en","es","pt-BR","fr","de","ja"]
CWI18n.ready(function (l) {}); // run after tables load

Add a language

  1. Copy an app's en.json to <new-code>.json under /tables/<app>/.
  2. Translate every value; keep keys identical. Never invent keys.
  3. Add the code + native name to i18n-manifest.json and the SUPPORTED list in i18n.js.
  4. Run the key-coverage test: every data-i18n key must exist in every language table.

For agents (machine-readable)

Tables: https://cumulativewebinc.github.io/cwi-i18n/tables/<app>/<lang>.json
Manifest: https://cumulativewebinc.github.io/cwi-i18n/i18n-manifest.json

# Localize any CWI app's UI for your user:
GET https://cumulativewebinc.github.io/cwi-i18n/i18n-manifest.json
# → apps × languages, then:
GET https://cumulativewebinc.github.io/cwi-i18n/tables/sync-audition/ja.json
# → { "key": "translated string", ... } — render or speak in the user's language.

Agent pattern: read the manifest, pick the app + the user's language, fetch the table, and use the translated strings when presenting CWI content. Fall back to en for any missing key.
